Move data between devices

Save an encrypted backup file on one device, then import it on the other. Nothing syncs automatically.
On the device that has your log: type a password for the file, then tap Save backup file. Send the file to your other device by email, AirDrop or Files. Remember the password, you'll need it to open the file.
On the device you're moving to: choose the backup file, enter the same password, then tap Import. Entries already on this device are skipped, so importing twice won't create duplicates.

Archive

Your list starts fresh each 1 January. Earlier years are kept here, and you can download each year as an Excel file.

Save your recovery code

If you ever forget your passcode, this code lets you set a new one without losing any entries. It is shown only once, so write it down or keep it in a password manager. Anyone who has this code and your device can open your log.
